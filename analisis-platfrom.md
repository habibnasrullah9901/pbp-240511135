# Analisis Komparatif Platform: Web, Desktop, dan Mobile

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, JavaScript/TypeScript (frontend); JS, PHP, Python, dll. (backend) | C++, C#, Java, Python; atau JavaScript via Electron | Kotlin/Java (Android), Swift (iOS); Dart (Flutter), JS (React Native) |
| Arsitektur | Client-server: browser meminta, server memproses dan merespons via HTTP/HTTPS | Aplikasi berjalan langsung di OS dan mengakses sumber daya sistem secara lokal | Aplikasi terpasang di perangkat dan berjalan di atas OS mobile, umumnya terhubung ke API/backend |
| Cara distribusi | Diakses lewat URL, deploy ke server/hosting/cloud | Installer (.exe, .msi, .deb, .dmg) atau toko aplikasi seperti Microsoft Store | Toko aplikasi (Google Play, App Store) atau file APK |
| Keunggulan | Lintas platform, tanpa instalasi, update instan untuk semua pengguna | Performa tinggi, akses penuh ke perangkat keras dan file sistem, bisa offline | Akses sensor (kamera, GPS), notifikasi push, mobilitas tinggi |
| Keterbatasan | Bergantung pada koneksi internet dan kompatibilitas browser; akses perangkat keras terbatas | Harus dibuat/disesuaikan per OS; distribusi dan update lebih rumit | Proses review toko aplikasi, fragmentasi perangkat, keterbatasan baterai dan layar |
| Contoh aplikasi | Google Docs, Tokopedia (web), Wikipedia | Visual Studio Code, Microsoft Word, Adobe Photoshop | WhatsApp, Gojek, Instagram |
